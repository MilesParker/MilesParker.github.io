Support and privacy pages for Miles Parker's apps, served by GitHub Pages at
https://milesparker.github.io/. Each app has its own folder, linked from index.html:

* `dialtone/`: https://milesparker.github.io/dialtone/, from `public/support/` in the Dialtone
  repository. Copy it here after changing it.

To add an app, give it a folder and a line in index.html.
